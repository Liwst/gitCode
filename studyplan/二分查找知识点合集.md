## 1. 二分查找思考思路

比如我给出一个简单的单调数组：[3, 4, 4, 5, 5, 5, 6, 7];

问题1. 找到第一个 > 5的元素的位置(下标)

```c++
// 伪代码
int q[] = [3, 4, 4, 5, 5, 5, 6, 7];
while(l + 1 != r){
    int mid = (l + r) / 2;
    if(isBlue(q[mid])) // isBlue是关于是否>5的分界线的相关条件,在这个思路中分为蓝红边界，蓝色永远代表满足条件的左边，红色永远代表不满足条件的右边，所以这里应该是<=5的条件；
        l = mid;
    else
        r = mid;
}

bool isBlue(int x){
    if(x <= 5)
        return true;
    else
        return false;
}
```

## 2. 浮点数二分

问题：需要你在-10000----10000之间查找给定n的三次方根；

```c++
#include<iostream>
#include<cmath>
#include<algorithm>
using namespace std;
double n;
bool check(double x){
    if(x * x * x <= n)
        return true;
    else
        return false;
}
int main(){
    cin >> n;
    double l = -100, r = 100;
    while(r - l > 1e-8){
        double mid = (l + r) / 2;
        if(check(mid)){
            l = mid;
        }
        else
            r = mid;
    }
    cout << l << endl;
    cout << r << endl;
    return 0;
}
```



因为浮点数的计算本身就有误差，所以优化循环部分，100次循环，精度肯定更好。2的100次大概 1e-30

```C++
#include<iostream>
#include<cmath>
#include<algorithm>
using namespace std;
double n;
bool check(double x){
    if(x * x * x <= n)
        return true;
    else
        return false;
}
int main(){
    cin >> n;
    double l = -100, r = 100;
    for(int i  = 0; i < 100; ++i){
        double mid = (l + r) / 2;
        if(check(mid)){
            l = mid;
        }
        else
            r = mid;
    }
    cout << l << endl;
    cout << r << endl;
    return 0;
}
```
